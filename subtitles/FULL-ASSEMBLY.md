# 八段完整合成

使用已确认的开头v8、第二段v3，以及第三至第八段成片。总长10080帧/336秒，即5分36秒，1920×1080、30fps。

边界：0、40.8、79.2、131.4、169.6、220.9、265.3、303.6、336.0秒。视频先移除分段音频，仅按精确视频时长连接；原画质主版本复制视频编码，不再次压缩画面。

对白从完整PCM主轨一次读取，音量0.70；背景音乐从连续轨一次读取，根据全局字幕以0.065×1.15/0.10×1.15压低/恢复，并做10毫秒音量平滑，末尾1.2秒淡出。去掉第二段独立预览时的边缘淡化。关键音效从各段代码提取，在全局帧位置重新混音，尾音允许跨段自然延续。最终AAC统一编码，避免分段AAC填充带来的停顿。

字幕从各段实际使用的帧级时间转换成全局SRT，既保留画面内字幕，也附带可选中文字幕轨。字幕仍为句级校准，未做逐字模型识别或人工听审。

- `out/top-student-full-master.mp4`：原画质合成版，视频流复制。
- `demo/top-student-full.mp4`：GitHub下载版，1080p、30fps，视频目标码率1800kbps，保留同一音轨和字幕。
- `subtitles/full-captions.srt`：全局字幕。

复现（需要原始音频及八段成片）：

```sh
npm run assemble:student-full
```

工具依赖：Node、FFmpeg、Python NumPy/SciPy。音频源及中间文件不提交到仓库。

## 检查结果

两版均为336.000秒、10080视频帧，音视频从0开始，完整解码无错误。七个拼接边界的首帧与对应原分段首帧逐一MD5比对相同。字幕147条，顺序及无重叠检查通过；224个音效按全局时间重新放置。混音综合响度−17.1 LUFS、真峰值−2.3 dBTP，无采样削波。原画质文件137125956字节，GitHub下载版83871814字节。源代码TypeScript检查通过。

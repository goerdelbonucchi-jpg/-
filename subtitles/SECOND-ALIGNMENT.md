# 第二段字幕与素材时间范围

- 完整主音轨范围：40.800–79.200秒（30fps第1224–2376帧，结束帧不包含）。
- 第二段本地范围：0–38.400秒，15条句级字幕。
- `second-captions.srt` 为第二段从零起算字幕。
- `second-master-time.srt` 为对应完整配音的绝对时间字幕。
- 文字来源：用户提供的学生、学霸SRT，结合文稿修正标点并拆分跨角色条目。
- 时间依据：`audio-match-anchors.json` 与 `audio-match-runs.json` 的原分轨→完整对白连续匹配；连续台词以约0.91倍原时长映射，换人边界用完整对白静音核对。
- 使用学霸连续匹配段的偏移约19.497、22.371、25.991、27.579秒，以及学生约35.250、43.265、48.809、51.101秒的偏移分别映射，不能使用统一偏移。
- 原SRT将“先算账”附在之前条目中，本段将它放回本段开头；“目标可以野，路径必须现实。继续走”拆成两个不同轮次。
- 音频直接从连续PCM主轨截取，音乐也从同一个全局位置续播。未重排或变速对白。
- 校准颗粒度为句级，未进行逐字强制对齐或人工听审，不以音轨零偏移作为字幕内容准确的证明。

## 复现

```sh
python3 scripts/build-second-captions.py
npm run check
npm run render:student-part-two
```

声音、人物与配色继承第一段：学生暖金色，学霸白色中空线稿；不说话的人可见度统一为12%；停顿保持上一位说话人的状态。

# 第三段：失败复盘

- 主音轨范围：79.200–131.400秒，第2376–3942帧（结束不包含）。
- 本段长度：52.200秒，25条句级字幕。
- 从“第二种，失败复盘思维”到学生说“讲吧”。下一段可从131.4秒续接，主音轨随后进入第三种思维。
- 文字取自用户的分轨SRT及文稿；换人边界以主音轨静音核对，句内分割主要沿用原SRT映射。未进行逐字强制对齐或人工听审。
- 学霸匹配段偏移约29.616、32.120、36.910、39.668、41.205、45.864秒；学生偏移约55.769、59.038、60.869、69.495、83.480、84.178、86.762秒。原轨/合并轨有约1.1倍速关系，不能统一加偏移。
- 相同的短字如“嗯”会产生模糊匹配，因此以连续对白顺序和主轨换人边界复核，而不单用单个相关系数。

## 外观与声音

学霸白色中空轮廓、学生黄色；静默角色12%可见度，停顿保持上一位说话人的状态。BGM沿用提高15%的设置：对白时0.065×1.15，停顿时0.10×1.15。对白0.70，关键动作配乐器音效。

BGM从原始音乐79.2秒位置续播，不在第三段开头重播或增加独立淡入。第二段的起点1224帧加1152帧正好等于本段起点2376帧。

## 合片约定

分段MP4为审片文件。最终合片应沿全局帧时间轴使用连续PCM对白和一条连续BGM，音效绑定全局时间。统一处理音乐压低和恢复，去除审片段首尾的局部音乐包络。超过原BGM时长时先制作交叉淡化循环，再统一混音与编码；不得只将带AAC尾帧的MP4音轨硬拼后当作最终成片。

## 重建

```sh
python3 scripts/build-third-captions.py
npm run check
npm run render:student-part-three -- --crf 21
```

`third-captions.srt`从本段0秒起算，`third-master-time.srt`沿用完整主音轨时间。

## 导出检查

TypeScript检查、25条字幕正时长/顺序/无重叠检查通过；关键画面已抽帧。H.264/AAC，1920×1080，30fps，视频52.2秒；音视频流起点均为0，解码无错误。综合响度−17.3 LUFS，真峰值−2.7 dBTP。音轨截取位置另用主音轨79.2秒起的PCM片段做波形对比；这不替代字幕逐字内容校准。
